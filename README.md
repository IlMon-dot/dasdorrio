# Сайт-прокладка Dasdorrio

Одна страница для шапки профиля в соцсетях. Человек приходит из ролика,
видит товар крупно на сцене в его цветах, выбирает другой товар в ленте
справа и уходит по таблетке на Wildberries, Ozon или в магазин dasdorrio.ru.
Сайт ничего не продаёт и денег не принимает.

**Адрес:** https://dasdorrio.shop/ (домен на reg.ru, DNS: четыре A-записи на GitHub Pages
и CNAME www; старый адрес https://ilmon-dot.github.io/dasdorrio/ перенаправляет сюда)

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | вся страница: разметка, стили, скрипт. После сборки не трогаем. |
| `products.js` | **список товаров — правится только он** |
| `edit.html` | редактор названий и ссылок: пишет `products.js` в репозиторий через GitHub API |
| `photo/` | `имя-hero.webp` герой, вырезанный из родной сцены; `имя-thumb.webp` миниатюра 200×200 (товар целиком, у наборов — только насос); `og.jpg` картинка для мессенджеров |
| `photo/bg/` | родная сцена товара без самого товара `имя.webp` (квадрат 1400 px, ≤ 130 КБ) |
| `logo/` | знак Dasdorrio: `dasdorrio.webp` для светлых сцен, `dasdorrio-light.webp` для тёмных, `-original.png` исходник |
| `PRODUCT.md`, `DESIGN.md` | контекст продукта и визуальная система для правок |

Внешнее: GSAP с CDN (анимации) и шрифты Unbounded и Onest с Google Fonts.
Без интернета страница откроется с системным шрифтом и без анимаций.

## Как поменять названия и ссылки

Редактор: **https://dasdorrio.shop/edit.html**. Там можно
переименовать товар, поменять подпись и адрес любой кнопки, добавить или
убрать кнопку, переставить кнопки и товары. Кнопка «Сохранить на сайт»
записывает `products.js` в репозиторий, сайт обновляется примерно через
минуту.

Один раз нужен токен GitHub (редактор запоминает его в браузере):
1. github.com → аватар → Settings → Developer settings → Personal access
   tokens → Fine-grained tokens → Generate new token
   (прямая ссылка: https://github.com/settings/personal-access-tokens/new).
2. Имя любое, срок — до года (потом создать заново так же).
3. Repository access → Only select repositories → `dasdorrio`.
4. Permissions → Repository permissions → Contents → Read and write.
5. Generate token → скопировать строку `github_pat_…` → вставить в редактор →
   «Подключить».

Токен никому не пересылать: он даёт право менять файлы этого репозитория.
Добавление новых товаров (фото, сцена, палитра) остаётся за агентом.

## Как добавить товар

Проще всего — сказать агенту: «добавь товар», дать ссылки на WB, Ozon и
магазин и 2–3 фото товара (лучше обложки с маркетплейса). Через Higgsfield
(MCP подключён) агент сгенерирует родную сцену товара по этим фото,
дорисует фон без товара, вырежет героя на его место, сделает миниатюру,
снимет палитру и допишет блок с `геройБокс`. Один товар — примерно 8–10
кредитов Higgsfield.

Вручную: открыть `products.js`, скопировать блок в фигурных скобках,
поменять `ключ`, `название`, пути к картинкам (`герой`,
`миниатюра`, `сцена`), `геройБокс`, `палитра` и `ссылки`. Порядок блоков = порядок в ленте, первым ставится то, что
продвигается сейчас. Нет товара на площадке — её строка
удаляется. Каждая ссылка — `{ вид, имя, адрес }`: вид задаёт цвет монетки
(`wb`, `ozon`, `market` — Яндекс Маркет, `shop` — dasdorrio.ru, `other` —
любая другая), имя — подпись кнопки, адрес — https-ссылка.

Палитра: `фон` — глубокий тон вуали под текстом (темнее самого товара, иначе
товар сливается с ней), `фон2` — ещё темнее, `акцент`/`акцент2` — цвета
деталей, `текст`/`текст2` — основной и вторичный текст (контраст к фону не
ниже 4,5:1), `логотип` — `светлый` на тёмной сцене, `тёмный` на светлой.

## Картинки

| Файл | Размер | Лимит |
|---|---|---|
| `имя-hero.webp` | вырезка из родной сцены, до 1200 px, без фона; положение в кадре — `геройБокс` | 150 КБ |
| `имя-thumb.webp` | 200×200, товар целиком, без фона | 18 КБ |
| `bg/имя.webp` | родная сцена без товара, квадрат 1400 px | 130 КБ |

Первый экран целиком должен весить не больше 300 КБ.

GitHub Pages разрешает браузеру держать файлы 10 минут, поэтому после замены
картинок агент поднимает метку `ВЕРСИЯ_КАРТИНОК` в `products.js` (картинки
грузятся с `?v=метка`), данные грузятся с меткой минуты, а страница сама
перезагружается один раз, если на сервере она новее.

## Метки UTM: откуда пришли

Метка ставится **до** решётки, иначе она не работает:

- верно: `https://dasdorrio.shop/?utm_source=instagram&utm_medium=bio#drakon`
- неверно: `https://dasdorrio.shop/#drakon?utm_source=instagram` — всё после решётки
  считается именем товара, метка теряется полностью.

Заготовки под шапки профилей:

| Где ссылка | Адрес |
|---|---|
| Instagram, шапка | `https://dasdorrio.shop/?utm_source=instagram&utm_medium=bio` |
| TikTok, шапка | `https://dasdorrio.shop/?utm_source=tiktok&utm_medium=bio` |
| YouTube, описание ролика | `https://dasdorrio.shop/?utm_source=youtube&utm_medium=video&utm_campaign=drakon#drakon` |
| VK, шапка | `https://dasdorrio.shop/?utm_source=vk&utm_medium=bio` |

Метрика берёт метку из первого просмотра визита и различает регистр, поэтому
значения пишем строчными и метку ставим на саму ссылку, а не на переход внутри
сайта. Отчёт: Отчёты → Источники → Метки UTM.

## Прямая ссылка на товар

`https://dasdorrio.shop/#ключ` открывает сразу нужный товар,
например `#drakon`. Удобно ставить в описание конкретного ролика.

## Как посмотреть локально

Через любой локальный сервер, например `python -m http.server 8765` в
папке проекта и открыть `http://localhost:8765/`. Двойной клик по
`index.html` тоже работает, но браузер может не подхватить шрифты.
После правки открывать страницу с параметром версии (`?v=2`), иначе
браузер покажет старую копию из кэша.

## Как выложить обновление

Сайт лежит на GitHub Pages, репозиторий `IlMon-dot/dasdorrio`, ветка `main`.
Всё, что попадает в `main`, через минуту появляется по адресу выше.

Проще всего — сказать агенту «выложи обновление». Вручную из папки проекта:

```bash
git add -A && git commit -m "что поменяли" && git push
```

Статус сборки: `gh api repos/IlMon-dot/dasdorrio/pages --jq .status`
(должно быть `built`). Если на телефоне видна старая версия — обновить
страницу с зажатой кнопкой или подождать пару минут, это кэш.

В репозиторий не попадают `.business/`, `Исходники/`, `.claude/`, `plans/`,
`CLAUDE.md` и `STARTER.md` — они перечислены в `.gitignore`.

## Аналитика

Счётчик Яндекс.Метрики 112528267 стоит в `<head>` файла `index.html` кодом
из кабинета (вебвизор выключен, карта кликов включена). Цели по кликам
(`marketplace_click`, `click_wb`, `click_ozon`, `click_shop`) и просмотры
товаров отправляет скрипт страницы; номер счётчика в нём указан явно.
Что считается и какие цели создать — в `.business/goals/kpi.md`.

**Если с какого-то компьютера заходы не считаются.** Открыть сайт, нажать F12,
вкладка Network, в фильтре набрать `mc.yandex`, обновить страницу и посмотреть
строку `tag.js?id=112528267`:

- `application/javascript` и около 240 КБ, затем запрос `watch/112528267` —
  счётчик работает, искать причину в фильтрах Метрики;
- `image/gif` и 43 байта, запроса `watch` нет — скрипт подменил антивирус
  (у Касперского это «Антибаннер» или «Защита от сбора данных»). Добавить
  `dasdorrio.shop` в разрешённые сайты этих компонентов или проверять с телефона.
