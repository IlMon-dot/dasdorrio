Доступ к сайту

Введите токен GitHub один раз — редактор запомнит его в этом браузере и будет сохранять правки прямо на сайт.

Как получить токен (один раз, 3 минуты)
  1. Откройте github.com/settings/personal-access-tokens/new (это Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token).
  2. Token name — любое, например «редактор сайта». Expiration — Custom, дата через год. Когда срок выйдет, создайте новый так же.
  3. Repository access → Only select repositories → выберите dasdorrio.
  4. Permissions → Repository permissions → Contents → Read and write. Больше ничего не включайте.
  5. Generate token → скопируйте строку github_pat_… (показывается один раз) → вставьте сюда → «Подключить».

Токен даёт право менять файлы этого репозитория — никому его не пересылайте. Он хранится только в вашем браузере, в код сайта не попадает.

Порядок карточек = порядок в ленте на сайте. Первый товар показывается при открытии.
